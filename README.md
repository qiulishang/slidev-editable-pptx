本仓库按 `versions/<semver>/` 保存历史快照，旧版本不会被新版本覆盖。

## 当前版本

- `0.0.1`

## 后续版本流程

1. 在 live skill 原文件基础上修改或调整。
2. 将 live skill 中的 `VERSION` 更新为下一个版本，例如 `0.0.2`。
3. 将 live skill 复制为本仓库的 `versions/0.0.2/`。
4. 同步更新仓库根目录 `VERSION` 为 `0.0.2`。
5. 提交 Git 并打标签 `v0.0.2`。
6. 推送到 GitHub 仓库。
